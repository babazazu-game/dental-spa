# Dental Spa — дизайн-концепция

Многостраничная статическая демонстрация на русском и казахском. HTML генерирует Python; анимация пользовательской 3D-модели работает в Three.js. Сборка не требует npm-зависимостей и внешних CDN.

## Локальный запуск

```powershell
python build.py
python check.py
python -m http.server 4173 --directory dist
```

Открыть http://localhost:4173/ru/ или /kk/. В Linux можно использовать python3.

## Сборка для GitHub Pages

```powershell
$env:SITE_BASE_PATH='/dental-spa'
python build.py
python check.py
```

В GitHub Pages публикуется корень ветки `gh-pages`. Исходный код находится в `main`. Для обновления после коммита `main`:

```powershell
git push origin main
git subtree push --prefix dist origin gh-pages
```

## Реализовано

- Главная с реальной пользовательской 3D-моделью: медленное автопокачивание, лёгкий отклик на курсор, отдельное движение фонового слоя; reduced motion, статичный резервный кадр, остановка рендера вне видимой области.
- Две языковые версии с сохранением текущей страницы при переключении, услуги, пять врачей, прайс с поиском, журнал, контакты, меню с клавиатурным управлением.
- Реальные фотографии и видео клиники; видео автоматически запускается в видимой области без звука; пауза по нажатию и отдельное управление звуком.
- Контакты и цены взяты с dentalspa.kz; административные позиции (носки, возврат, аванс) исключены из клиентского прайса.
- Горизонтальный логотип составлен из двух CSS-областей исходного изображения: знак и текст не перерисованы.
- Сайт помечен как дизайн-концепция и закрыт от индексации.

## Демонстрационные части

Запись открывает окно с телефоном клиники. Данные пациентов не собираются; календарь, CRM, DeepSeek, Telegram и WhatsApp API не подключены. Отзывы ведут на реальные площадки, без выдуманных оценок. Материалы журнала представлены сокращённо; ссылка ведёт на полную публикацию клиники. Казахские тексты и медицинские термины требуют проверки клиникой перед официальным запуском. Даты стажа и актуальность прайса также нужно подтвердить у владельца.

Контент, публичные материалы и прайс: dentalspa.kz. 3D-модель предоставлена заказчиком. Three.js — MIT; Montserrat — SIL OFL. Лицензии шрифта и Three.js сохранены в assets.
